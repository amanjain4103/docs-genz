
## Why I'm Building This (Ground Reality & Core Pain Points)

Most legal drafting and court documentation work runs on outdated software, low-spec dual-core desktop machines, or messy Word templates. Every typist, advocate, and document writer deals with the exact same frustrating issues every single day:

1. **The 40+ Page Lag (P0):** Opening a bulky petition or civil suit in heavy software crawls to a halt. Keystroke lag kicks in, scrolling stutters, and printing locks up the entire machine.
2. **Low-Spec Hardware Reality (P0):** Most court chambers, paralegals, and local typing setups run 4GB RAM PCs (often on older Windows or Linux). Software built on heavy frameworks eats all memory and crashes.
3. **Template Copy-Paste Chaos (P0):** Right now, to make a new affidavit or deed, the only option is opening an old client's file, doing `Save As`, and manually replacing names. Miss one name on page 4, and an old client’s father's name or case number stays in the final print.
4. **No Form-Based Drafting (P0):** A legal document is basically structured data (Petitioner, Respondent, Date, Claim Amount, Stamp Value) wrapped around legal language. There is no simple tool where you fill out a clean form on the side and have the entire document populate automatically.
5. **Client-Specific Additions:** While 90% of an agreement or deed is fixed boilerplate, there is always 1 or 2 custom clauses that need manual tweaking per client without messing up the rest of the template layout.
6. **Hindi Font & Skilled Typist Bottleneck (P0):** Skilled Kruti Dev typists are expensive and hard to find. New staff struggle with legacy key mappings. There is no seamless way to write in Unicode (Mangal/InScript) while keeping legacy Kruti Dev compatibility for older court offices that demand it.
7. **Stamp Paper Alignment Nightmare (P0):** Printing on ₹50, ₹100, or ₹500 Non-Judicial stamp papers or leaving room for court fee tickets means hitting Enter multiple times to push text down on Page 1. If line spacing or font size changes slightly, the entire document shifts and the stamp paper print is ruined.
8. **Manual ID Data Entry:** Typists manually copy names, father names, and addresses off Aadhaar or PAN cards, introducing typos in basic details.
9. **No Context-Aware Legal AI:** Generic AI tools write generic essays. There is no lightweight tool that takes rough client facts and turns them into clean, jurisdiction-ready court averments.
10. **Zero Backup Habits:** Local drafts sit scattered across random desktop folders without proper backup or quick search.
